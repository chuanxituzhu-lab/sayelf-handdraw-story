## 已通过

- 核心规则：空输入与超长输入拒绝；16 个示范自动得到不同帧数；长文片段与结尾保留；图片条目数与视频镜头数始终相等；镜头编号和时间连续。
- 数据边界：故事文件版本/字段/编号/时长校验；重复编号、坏画风、缺字段被拒绝；SVG 文本转义；CSV 公式前缀防护。

- 安全：页面没有外部脚本、iframe、Beacon、localStorage 或 sessionStorage；AI 请求仅由用户按钮触发；离线浏览器测试的网络请求与页面错误均为 0；故事 JSON 不包含 API key。
